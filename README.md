## 📌 Overview

This project analyzes e-commerce transaction data to understand **customer behavior, revenue patterns, and business performance**.

The analysis focuses on customer spending, revenue trends, country-wise performance, and customer contribution to overall revenue.

---

## 📈 Analysis

### 💰 Revenue Trend

![Revenue Trend](images/revenue.png)

- Analyzed revenue changes over time
- Identified peak and low revenue periods
- Examined overall revenue patterns

### 🌍 Top Countries by Revenue

![Top Countries](images/top_countries.png)

- Compared revenue across countries
- Identified high-performing regions
- Analyzed geographic revenue contribution

### 👥 Customer Insights

- Identified high-value customers
- Analyzed customer spending behavior
- Compared new and repeat customers
- Examined customer contribution to total revenue

---

## 🔍 Key Insights

- A relatively small group of customers contributes a significant share of total revenue.
- Revenue varies across different time periods.
- Customer purchasing behavior differs across countries.
- Repeat customers contribute significantly to overall revenue.
- Revenue concentration can be analyzed using the **Pareto principle**.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/AnkanXcoder/ecommerce-business-insights.git
```

### 2. Navigate to the project

```bash
cd ecommerce-business-insights
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the notebook

Open the notebook inside the `notebook/` folder using **Jupyter Notebook** or **VS Code**.
